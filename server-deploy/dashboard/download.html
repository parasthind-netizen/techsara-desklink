DeskLink

Download and install this small app so your support agent can view your screen and help you remotely.

Download for Windows

Windows 10 / 11  ·  ~80 MB (ZIP)  ·  Free  ·  direct installer (.exe)

How to install

1
Click the button above and save the file. If Windows asks, click "Keep".
2
Open the downloaded ZIP, right-click → Extract All, then run DeskLink-Setup.exe. If you see a "Windows protected your PC" warning, click "More info" → "Run anyway".
3
The DeskLink app opens and asks for your installation code — type in the 9-digit code your support agent gave you.
4
That's it — your computer now shows as Available on the support dashboard, and stays available until you click "Disable Support Access" in the app.
Download for Mac (Apple Silicon)

macOS 11+  ·  ~100 MB (DMG)  ·  Free  ·  Intel Mac version
Most Macs from 2020 on are Apple Silicon (M1/M2/M3/M4). Older Macs need the Intel version.

How to install

1
Click the button above, then open the downloaded DeskLink.dmg and drag DeskLink into the Applications folder.
2
Open DeskLink from Applications. If macOS warns about the app, right-click it → Open → Open (or go to System Settings → Privacy & Security and click "Open Anyway").
3
Type in the 9-digit installation code your support agent gave you.
4
The app asks for two macOS permissions — Screen Recording and Accessibility. Click Grant on each, switch DeskLink ON in System Settings, then press "Restart DeskLink" in the app.
5
Done — your Mac now shows as Available on the support dashboard, and stays available until you click "Disable Support Access" in the app.

Your support team can only connect while the app shows Active — click "Disable Support Access" at any time to stop being reachable, or "Disconnect Session" to end a live session instantly.

DeskLink keeps itself running in the background (system tray / menu bar) so your support team can help even after a restart. To remove it completely, uninstall it like any other app.

Some antivirus tools may warn about this app because remote-assistance software can control the screen — that is exactly what it is for. It is safe to keep and install.
